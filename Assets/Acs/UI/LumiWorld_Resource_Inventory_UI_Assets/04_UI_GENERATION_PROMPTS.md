# LumiWorld — Step 09 Resource/Inventory UI: prompt archive

Các prompt dưới đây ghi lại định hướng của bộ asset. Màu HEX là mục tiêu mỹ thuật; ảnh tạo sinh có độ chênh màu và chi tiết nhẹ. Giữ Image Color trắng khi import để xem màu gốc.

## Style chung

```text
Use case: stylized-concept. Asset type: an individual production-ready 2D game UI sprite for LumiWorld, an original bright cozy fantasy nature game. Create exactly ONE UI asset, not a screenshot, mockup, contact sheet or sprite sheet. Visual direction: the readable, elegant bright anime fantasy RPG interface family of Genshin and Aniimo; original understated botanical design. Straight-on orthographic 2D artwork with refined clean edges, solid calm color surfaces, very light painted highlights, no perspective, no realistic material grain. Fixed palette: warm ivory #F7F2E8, inset ivory #EEE7D7, soft sage #78936D, dark forest outline #435B45, restrained pale gold #C6AE78. True transparent RGBA background outside the object, preserve transparency; opaque filled panel surfaces where specified. Crisp silhouettes readable at game UI scale. Fine warm outline and pale-gold inner rim, small rounded corners, no ornate rococo scrolls. Decoration must stay in corners, leave middle and all stretchable edge segments plain and straight for Unity 9-slice. No lettering, numbers, logos, watermarks, resource icons, other UI controls, scene or background. No drop shadow outside the sprite. Fill the canvas tightly with the requested asset, with only a small transparent safety margin.
```
